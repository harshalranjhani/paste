# v0.1.2

This release adds custom and short random paste slugs and CLI self-updates.

- Browser Sharing settings, the JSON and bundle APIs, and `pbin create` accept
  custom slugs or short/long random selection. Long random remains the default;
  short random uses 8 characters. Duplicate custom slugs cannot overwrite pastes.
- `pbin version` (or `--version`) reports the installed release. Release archives
  embed the tag; Go installations use the module's build metadata.
- `pbin update` installs the latest stable release for the current OS and CPU.
  It verifies the archive's checksum and runs the candidate's version command
  before replacing the installed executable. Login settings are preserved.
- Current or newer installed releases skip downloads. Download, checksum, archive,
  executable validation, and directory permission failures keep the old CLI usable.
- Existing symlink installations continue to point to the updated executable.
  Windows uses a backup and restores it if replacement fails.
- See [the CLI instructions](../README.md#update-an-installed-cli) for updating,
  downloading again, and upgrading a version that predates the update command.

Public CLI execution with external release HTTP fixtures verifies self-updates,
failure behavior, and rerunning the installed executable. CI runs these checks
on Linux, macOS, and Windows before publishing the release. The full Go suite and
browser flows retain burn-after-read, previews, and slug coverage.
