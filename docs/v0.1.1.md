# v0.1.1

This release extends the frozen MVP with burn-after-read and file previews.

## Burn-after-read

- Enable it in the browser sharing settings, with `burn_after_read: true` in
  single-file JSON or bundle metadata, or with `pbin create --burn`.
- Opening a link or reading metadata never consumes the paste. No file content
  is accessible before an explicit reveal POST.
- Password-protected pastes must be unlocked before reveal. Wrong passwords,
  invalid CSRF tokens, and HEAD requests never consume a paste.
- Exactly one browser can reveal a paste, including concurrent requests.
- The winning browser has a 15-minute lease to refresh, browse files, view
  previews, copy raw content, and download ZIPs. Other browsers receive 410.
- Lease expiry blocks access and cleanup deletes the file bodies. The paste's
  original expiry still applies and can end access sooner.

## File previews

- The existing viewer offers Code and Preview for Markdown (`.md`, `.markdown`)
  and HTML (`.html`, `.htm`) files. Other text files retain syntax highlighting.
- Markdown supports headings, lists, links, fenced code, tables, and task lists.
- HTML and Markdown render in sandboxed frames. Uploaded scripts, forms,
  external resources, and access to the parent application are blocked.
- File switching, browser history, theme changes, mobile selection, raw access,
  copying, and ZIP downloads retain the existing viewer behavior.
